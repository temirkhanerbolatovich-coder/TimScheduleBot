# TimScheduleBot

Личный Telegram-бот для расписания, рабочих смен и расчёта заработка. Управление через кнопки, данные в SQLite, работа на собственном сервере без включённого компьютера.

![Tests](https://github.com/temirkhanerbolatovich-coder/TimScheduleBot/actions/workflows/tests.yml/badge.svg)

**Версия 1.5.0 · Python 3.11+ · один владелец · интерфейс на русском**

## Возможности

- Планы на сегодня, завтра и неделю, календарь месяца с выбором дня.
- Разовые события и еженедельные занятия, ночные смены и предупреждения о пересечениях.
- Пошаговое добавление смен: тип, роль, дата и подтверждение.
- Роли «Админ» и «Помощник», настраиваемые ставки, часы и расчёт оплаты.
- Итоги месяца и недели, список смен и отметки «отработал», «меня заменили», «я заменил».
- Ближайшее событие, свободные интервалы, журнал и отмена последних изменений записей.
- Ежедневная и недельная сводки, резервные копии, статус и уведомления о сбое службы.

## Быстрый старт

Создай своего бота через BotFather. Затем:

```powershell
git clone https://github.com/temirkhanerbolatovich-coder/TimScheduleBot.git
cd TimScheduleBot
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

В `.env` вставь свой токен после `TELEGRAM_BOT_TOKEN=`. Не публикуй этот файл. Часовой пояс по умолчанию — `Asia/Qyzylorda`.

```powershell
.\.venv\Scripts\python.exe run_bot.py
```

Открой показанную при запуске ссылку привязки в Telegram и нажми Start. Код действует 10 минут. После привязки бот принимает сообщения только владельца. На Windows также можно использовать `START_BOT.cmd` после установки зависимостей.

Для Linux используй `python3 -m venv .venv`, `.venv/bin/python -m pip install -r requirements.txt`, скопируй `.env.example` в `.env` и запусти `.venv/bin/python run_bot.py`.

## Примеры

```text
20.11.2026 - Ночь (Админ)
21.11.2026 - День 8ч. (Помощник)

Понедельник:
Английский с 14:00 до 17:00, 402А, Преподаватель
```

Бот показывает предпросмотр перед сохранением. Для управления открой «Мои записи». Команды также доступны: `/today`, `/week`, `/calendar`, `/summary`, `/month`, `/history`, `/rates`, `/next`, `/free`, `/undo`, `/journal`, `/status`.

## Устройство

| Модуль | Назначение |
|---|---|
| `bot.py` | Меню, команды, callback и сводки |
| `parsing.py`, `formatting.py`, `message_format.py` | Разбор заметок, карточки и безопасная HTML-разметка |
| `store.py` | SQLite, подтверждения, исключения серий и история |
| `shifts.py`, `payroll.py`, `monthview.py`, `queries.py` | Смены, оплата, календарь и выборки |
| `telegram_api.py`, `run_bot.py` | Telegram API, привязка владельца и polling |
| `backup_database.py`, `alert.py`, `status.py` | Копии базы, уведомления о сбое и диагностика |

Внешняя нейросеть не используется. На Windows база часовых поясов устанавливается через `tzdata`.

## Проверка

```bash
python -X utf8 -m unittest -q
python -m pip check
```

83 теста проверяют разбор, подтверждения, изоляцию владельца, интерфейс, смены, оплату, календарь, копии и запуск. GitHub Actions запускает тесты на Windows и Ubuntu с Python 3.11 и 3.12. Локальный прогон не заменяет проверку конкретного серверного развёртывания.

## Ограничения

Это персональный планировщик. Разбор рассчитан на явные даты и время; голосовые сообщения и произвольная речь не поддерживаются. Оплата — оценка по заданным ставкам: без налогов, надбавок и бухгалтерского учёта. Вся смена относится к месяцу даты начала. Ставка фиксируется в каждой смене. Отчёты разделяют запланированные суммы, завершённые смены без отметки и подтверждённую работу; заменённые смены исключаются. Подробнее: [учёт оплаты](docs/payroll.md).

Публичная публикация исходников сама по себе не обновляет работающий сервер. Лицензия на дальнейшее распространение и использование пока не выбрана автором; отдельная open-source лицензия не заявляется.
