# Участие в разработке

Создайте ветку от main, внесите небольшое связное изменение и запустите `python -X utf8 -m unittest -q`. Для изменения поведения добавьте регрессионный тест и обновите README или CHANGELOG. Используйте вымышленные данные. Не добавляйте секреты, базы и результаты локального запуска.

В pull request укажите проблему, поведение после изменения, выполненные проверки и ограничения. Автоматический выпуск на сервер не настроен.
