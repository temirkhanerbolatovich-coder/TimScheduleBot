# Безопасность

Не публикуйте токены, ключи SSH, содержимое `.env`, базы SQLite и резервные копии. Примеры в репозитории обезличены. Бот предназначен для одного владельца; привязка использует одноразовый код.

Сообщайте об уязвимостях автору приватно через контакт в профиле GitHub. Не создавайте публичный issue с секретами или личными планами. При раскрытии токена отзовите его через BotFather и замените в серверной конфигурации.
